# ADR 0004: 配当の年次・半期集計はカレンダー年（1-12 月）基準とする

## Status

Accepted (2026-06-12)

## Context

配当の合計額を「年」「半期」単位で集計する要件があり、その「年」を以下のいずれで定義するかを決める必要があった：

- カレンダー年（1 月 - 12 月）
- 日本の会計年度（4 月 - 翌 3 月）

## Decision

カレンダー年（1 月 - 12 月）基準で集計する。半期は 1-6 月 / 7-12 月で区切る。

### 理由

- 個人投資の確定申告・税務管理がカレンダー年基準であり、ユーザーの実利用と合致する
- 半期区切りも上半期 / 下半期として直感的

## Consequences

- 集計 API（例：`/api/dividends/summary`）はカレンダー年・半期で集計値を返す
- 将来「会計年度切り替え」を要求された場合は、集計 API にパラメータを追加して切り替える設計を検討する

## 見直しトリガー

- 会計年度（4-3 月）や任意の期首月での集計要求が出たとき（→ 集計 API にパラメータを追加、Consequences 既述）
- 確定申告・税務の基準が暦年から変わる、あるいは米国株の課税年度を別基準で集計したい要求が出たとき
