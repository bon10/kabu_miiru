## 株価・損益計算ルール

### BR-100: 損益計算
```
未実現損益 = (現在価格 × 保有株数) - 投資額
損益率 = 未実現損益 ÷ 投資額 × 100
```

**適用条件**:
- 保有株数 > 0の銘柄のみ
- 投資額 > 0の場合のみ損益率計算
- ゼロ除算回避: 投資額 = 0の場合、損益率 = 0

### BR-101: 平均取得単価計算
```
// 初回購入時
平均取得単価 = 購入単価

// 追加購入時  
新平均取得単価 = (既存投資額 + 追加投資額) ÷ (既存株数 + 追加株数)

// 売却時（平均取得単価は変更しない）
平均取得単価 = 既存平均取得単価
```

### BR-102: 投資額計算
```
投資額 = Σ(購入取引の総額)
売却時投資額減算 = 平均取得単価 × 売却株数
```

### BR-103: 実現損益計算
```
実現損益 = 売却額 - (平均取得単価 × 売却株数) - 手数料
```

## 配当計算ルール

### BR-200: 年間配当金額（予想）の概念式
```
年間配当金額（予想） ≒ 1株配当金（予想 DPS） × 保有株数
```

**対象**: 銘柄マスタの予想値（`Stock.dividendAmount`＝予想年間配当、`Stock.dividendPerShare`＝予想 DPS）。上式は両者の**概念的な関係**を示すもので、実際の受取額（BR-202）とは別物。

**実装の注意**: 現状アプリは `Stock.dividendAmount` と `Stock.dividendPerShare` を **TSV インポート列からそれぞれそのまま取り込む**（[import/tsv/route.ts](../../src/app/api/import/tsv/route.ts)）。`dividendPerShare × 保有株数` で `dividendAmount` を再計算する処理は持たないため、両者が上式どおり一致する保証はインポート元データに委ねられている。

### BR-202: 受取配当金額計算（実績）
```
配当・分配金合計（税引前） = 1株あたり配当金 × 数量
受取金額（手取り）         = 配当・分配金合計 − 税額合計
税額合計                   = 配当・分配金合計 − 受取金額
```

**対象**: 実際に受け取った配当の 1 件（`DividendHistory`）。証券会社の**配当明細 1 行をそのまま写す**（ADR 0015）。単価（1 株あたり配当金）と数量から配当・分配金合計を確定し、**税額合計と受取金額はどちらか片方**を入力すればもう片方が上式で埋まる。

**適用条件**:
- 1 株あたり配当金 > 0
- 数量 > 0。**数量はユーザーが明細から入力する必須項目**で、現在の保有株数（`Stock.sharesHeld`）は使わない。配当額は権利確定日の株数で決まるのに対し、`sharesHeld` は権利確定後の売買を織り込んだ別の数字だから（ADR 0015）。未入力を保有株数で補うこともしない
- 税額合計・受取金額は 0 以上、かつ配当・分配金合計以下
- **税額合計と受取金額が両方入力されたら引き算せずそのまま採り、合計との一致は検証しない**。米国株は明細の税額合計が空欄（現地源泉徴収税が出ない）で「税額合計 + 受取金額 ≠ 配当合計」になりうるため
- 両方未入力なら税額不明として NULL で保存する
- 計算は受取通貨（JPY / USD）建てのまま行う。円換算は集計・表示時に当日レートで行う（ADR 0006）

### BR-203: 受取配当の集計基準
```
集計に使う金額 = 受取金額（手取り）。無ければ配当・分配金合計（税引前）で代用
```

**対象**: YTD 配当・年計・半期・銘柄別・推移グラフの累計配当（ADR 0015）。`DividendHistory.netAmount` を使い、**NULL のときだけ `dividendAmount` で代用**する。

**適用条件**:
- ADR 0015 より前に登録したレコードは `netAmount` を持たないため、**集計対象に税引前と手取りが混ざる**。既存データは移行しない
- 予想年間配当（`Stock.dividendAmount`）は税引前のままなので、実績と並べる箇所ではラベルで基準を区別する
- 実装は [netDividendAmount](../../src/lib/dividend.ts)

### BR-201: 配当利回り計算
```
配当利回り = (1株配当金 ÷ 現在価格) × 100
```

**適用条件**:
- 現在価格 > 0の場合のみ
- ゼロ除算回避: 現在価格 = 0の場合、配当利回り = 0

## 株価取得ルール

### BR-300: 銘柄コード変換
- **日本株**: 数字コード（例：7203）→ API呼び出し用コード（7203.T）
- **米国株**: ティッカーシンボル（例：AAPL）→ そのまま使用

### BR-301: 価格更新対象
- **対象**: 保有株数 > 0の銘柄のみ
- **除外**: 売却済み銘柄（保有株数 = 0）
- **エラー処理**: 個別銘柄の取得失敗は全体処理を停止しない

### BR-302: 価格更新タイミング
- **自動実行**: 平日11:30（前場終了後）、15:00（後場終了後）
- **手動実行**: ユーザーの任意タイミング
- **休場日除外**: 土日祝日、年末年始は実行しない

## ポートフォリオ集計ルール

### BR-400: 全体サマリー計算
```
全体投資額 = Σ(各銘柄の投資額)
全体損益 = Σ(各銘柄の未実現損益)
全体損益率 = 全体損益 ÷ 全体投資額 × 100
全体配当金額 = Σ(各銘柄の年間配当金額)
```

### BR-401: 市場別集計
```
国内株投資額 = Σ(市場='国内'の銘柄投資額)
米国株投資額 = Σ(市場='米国'の銘柄投資額)
```

### BR-402: 証券会社別集計
```
証券会社別投資額 = Σ(保有会社別の銘柄投資額)
証券会社別損益 = Σ(保有会社別の銘柄損益)
```

## データ整合性ルール

### BR-500: 取引履歴整合性
```
銘柄保有株数 = Σ(購入取引株数) - Σ(売却取引株数)
```

**検証タイミング**:
- 取引データ追加・編集時
- データインポート時
- 定期的な整合性チェック

### BR-501: 投資額整合性
```
銘柄投資額 = Σ(購入取引総額) - Σ(売却時投資額減算)
```

### BR-502: 売却制約
- **制約**: 売却株数 ≤ 売却時点の保有株数
- **チェック**: 売却取引入力時の事前検証
- **エラー**: 制約違反時は取引を拒否

## 通貨・精度ルール

### BR-600: 数値精度
- **金額**: 小数点以下2桁（DECIMAL(15,2)）
- **株価**: 小数点以下4桁（DECIMAL(15,4)）
- **株数**: 小数点以下4桁（DECIMAL(15,4)）
- **パーセント**: 小数点以下4桁（DECIMAL(8,4)）

### BR-601: 四捨五入規則
- **表示用**: 小数点以下指定桁数で四捨五入
- **計算用**: 内部計算は精度を保持
- **最終表示**: UI表示時に適切な桁数に丸め

## 時間・日付ルール

### BR-700: 日付処理
- **取引日**: YYYY-MM-DD形式
- **時刻**: システム時刻はUTC、表示は日本時間
- **営業日判定**: 平日かつ祝日でない日

### BR-701: 価格更新時刻
- **前場**: 11:30（JST）
- **後場**: 15:00（JST）
- **時間外**: 上記以外の時間帯での手動更新

## エラー処理ルール

### BR-800: 計算エラー処理
- **ゼロ除算**: 分母が0の場合、結果を0またはNULLに設定
- **数値オーバーフロー**: 適切な桁数制限とエラー通知
- **データ不整合**: 警告表示と修正提案

### BR-801: API エラー処理
- **接続エラー**: リトライ後、手動更新を促す
- **データエラー**: 異常値検出時は更新をスキップ
- **レート制限**: 適切な間隔での再実行
