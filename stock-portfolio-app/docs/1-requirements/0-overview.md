# 機能要件 - 概要

## プロジェクトスコープ

個人株式投資管理アプリの最優先機能（5つ）に絞り込んだ要件定義。提供されたTSVデータをベースに銘柄管理を網羅し、シンプルで実用的なポートフォリオ管理を実現する。

## 主要機能一覧

1. **[銘柄一覧機能](./stock-management.md)** - TSVベースの包括的な銘柄データ管理
2. **[ポートフォリオサマリー機能](./portfolio-summary.md)** - 全体損益・配当・投資額の統計
3. **[視覚化分析機能](./portfolio-visualization.md)** - 構成比率とパフォーマンスの視覚化
4. **[取引履歴管理機能](./transaction-management.md)** - 売買・配当取引の詳細記録と分析
5. **[株価自動取得機能](./price-update.md)** - 定期的な価格更新とリアルタイム損益計算

## 対象外機能

以下の機能は今回の開発対象外とする：

- 銘柄検索・ウォッチリスト機能
- 配当カレンダー表示
- パフォーマンス分析（シャープレシオ・ボラティリティ）
- 投資スタイル分析
- 自動レポート生成
- 証券会社API連携
- ユーザー認証（初期版は単一ユーザー想定）

## 開発優先度

1. **Phase 1**: 銘柄一覧機能 + ポートフォリオサマリー機能
2. **Phase 2**: 取引履歴管理機能 + 視覚化分析機能
3. **Phase 3**: 株価自動取得機能
