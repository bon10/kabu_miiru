# ポートフォリオサマリー機能要件

## 機能概要

全証券会社横断でのサマリー情報を表示する。投資全体の状況を数値で把握し、パフォーマンスを一目で確認できる機能。

## 表示項目

### 主要指標
- **全体損益**: ¥137,341（例）
- **全体配当金額**: ¥13,842（例）
- **全投資額**: ¥717,118（例）
- **全損益率**: 19.15%（例）

### 詳細統計
- **保有銘柄数**: 現在保有中の銘柄数
- **証券会社数**: 利用している証券会社数
- **現在評価額**: 投資額 + 損益
- **最終更新日時**: データの最終更新タイミング

### 市場別内訳
- **国内株式**:
  - 投資額、損益、保有銘柄数
- **米国株式**:
  - 投資額、損益、保有銘柄数

## 機能要件

### FR-010: サマリー情報表示
- **説明**: ポートフォリオ全体のサマリー情報をダッシュボードに表示
- **更新頻度**: リアルタイム（価格更新時に自動計算）
- **表示形式**: カード形式でのKPI表示

### FR-011: 市場別集計
- **説明**: 国内株式・米国株式別の集計情報表示
- **集計項目**: 投資額、損益、損益率、銘柄数
- **比較表示**: 市場間のパフォーマンス比較

### FR-012: 証券会社別集計
- **説明**: 証券会社別の集計情報表示
- **集計項目**: 投資額、損益、保有銘柄数
- **詳細表示**: 会社別の詳細データ表示

### FR-013: 履歴トレンド
- **説明**: サマリー情報の時系列変化表示
- **期間**: 日別、週別、月別
- **グラフ**: 線グラフでの推移表示

## 計算仕様

### 全体損益計算
```
全体損益 = Σ(各銘柄の損益)
各銘柄の損益 = (現在価格 × 保有株数) - 投資額
```

### 全体損益率計算
```
全体損益率 = 全体損益 ÷ 全投資額 × 100
```

### 配当金額計算
```
全体配当金額 = Σ(各銘柄の年間配当金額)
各銘柄の年間配当金額 = 1株配当金 × 保有株数
```

### 投資額計算
```
全投資額 = Σ(各銘柄の投資額)
```

## 技術要件

### パフォーマンス要件
- **計算速度**: 100銘柄以下で500ms以内
- **データ整合性**: 価格更新時の即座反映
- **キャッシュ**: 集計結果のキャッシュ機能

### データ精度
- **小数点処理**: 金額は小数点以下2桁まで
- **四捨五入**: 損益率は小数点以下2桁で四捨五入
- **通貨表示**: 日本円は¥表記、米ドルは$表記

## 受入条件

### AC-010: サマリー計算精度
- Given: 複数銘柄のデータが存在する
- When: サマリー情報を表示する
- Then: 手動計算と一致する正確な数値が表示される

### AC-011: リアルタイム更新
- Given: 株価が更新される
- When: 価格データが変更される
- Then: サマリー情報が即座に更新される

### AC-012: 市場別集計
- Given: 国内株と米国株が混在する
- When: 市場別集計を表示する
- Then: 正しく市場別に分類・集計される

### AC-013: ゼロ除算対策
- Given: 投資額が0の状態
- When: 損益率を計算する
- Then: エラーにならず適切に処理される
