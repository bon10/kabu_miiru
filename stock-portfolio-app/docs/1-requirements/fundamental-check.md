# 基準チェックの画面要件

## 機能概要

保有銘柄が、銘柄選びのスキル（value-stock-screener）と同じ基準を今も満たしているかを、所有者が画面で確かめる機能。

判定のしきい値・計算・保存は [ADR 0021](../7-adr/0021-fundamental-check-for-holdings.md) と [fundamental-check.ts](../../src/lib/fundamental-check.ts) が決める。**この文書は、その判定を画面でどう見せるか（どの画面に何を出すか、どの言葉で書くか）を決める。** 判定の中身は扱わない。

所有者は投資の専門家ではないため、判定の名前だけを出さず、**その判定が何を意味するか**と**次にすること**を同じ場所に書く。

## 判定ごとに画面に出す言葉

判定の値（`CheckStatus`）ごとに、ラベルと一文を [fundamental-check-card.tsx](../../src/components/stocks/fundamental-check-card.tsx) の `STATUS_LABEL` / `STATUS_SUMMARY` に持つ。3 つの画面で同じ言葉を使う。

| 判定 | 画面のラベル | 画面に出す一文 |
| --- | --- | --- |
| `broken` | 見直し対象 | 買ったときは満たしていた基準を、今は下回っています。この銘柄を持ち続けるか、もう一度考えるきっかけです。 |
| `unmet` | 購入時から未達 | 買った時点で基準に届いていない項目があります。買ったあとに悪くなったものはないので、今すぐすることはありません。 |
| `ok` | 満たしている | すべての基準を満たしています。今はすることはありません。 |
| `no_data` | データなし | 財務の値がまだありません。ヘッダーの「価格更新」を押すと取りに行きます。 |
| `not_applicable` | 対象外 | ETF は財務の値が無いため、基準チェックの対象外です。 |

項目ごとの判定（`CheckItemStatus`）は、銘柄の判定と違い「次にすること」ではなく「その項目に何が起きたか」を書く。

| 項目の判定 | 画面のラベル |
| --- | --- |
| `ok` | 満たしている |
| `broken` | 買ったあとに下回った |
| `unmet_since_purchase` | 購入時から未達 |
| `no_data` | データなし |

## 項目ごとの説明

数字の意味が分からないと次の行動を決められないため、項目名のとなりに 1 文の説明を出す。文言は [utils.ts](../../src/lib/utils.ts) の `FUNDAMENTAL_CRITERION_HINT` に持つ。しきい値はここには書かない（基準の列で出す）。

| 項目 | 画面に出す説明 |
| --- | --- |
| ROE | 集めたお金でどれだけ稼げているか。低いほど稼ぐ力が弱いという見方です。 |
| FCF利回り | 手元に残る現金が、株価に対してどれだけあるか。マイナスは現金が出ていっている状態です。 |
| 自己資本比率 | 借金に頼らず自分のお金で事業をしているか。高いほど倒れにくいという見方です。 |
| 有利子負債倍率 | 利息の付く借金が自分のお金より多くないか。100% を超えると借金のほうが多い状態です。 |
| Altman Z | 倒産しにくさの目安。低いほど危ないという見方です（米国株で使います）。 |
| 200日線 | ここ 200 日の平均の株価より、今が上か下か。下なら下がり気味ということです。 |

## 判定を出す 3 つの画面

| 画面 | 出すもの | 読み出し |
| --- | --- | --- |
| 基準チェック一覧（`/fundamental-checks`） | 判定ごとの件数、基準に届いていない銘柄の一覧 | `GET /api/fundamental-checks` |
| 保有一覧（`/holdings`） | 件数の要約バー、見直し対象の銘柄だけに付く印 | `GET /api/fundamental-checks` |
| 銘柄詳細（`/stocks/[id]`） | その銘柄 1 件の項目ごとの内訳 | `GET /api/fundamental-checks?stockId=` |

### 基準チェック一覧

[fundamental-checks-client.tsx](../../src/components/stocks/fundamental-checks-client.tsx)。上から次の順に出す。

1. **判定ごとの件数**（見直し対象・購入時から未達・満たしている・対象外の 4 つ）。見直し対象だけ色を付け、ほかは同じ見た目にする。枠ごとに「所有者がすること」を 1 文添える。`no_data` が 1 件以上あるときだけ、件数を枠の下に文で出す
2. **基準に届いていない銘柄の表**。1 行 1 銘柄で、丸い印・銘柄名（銘柄詳細へのリンク）・コード・市場・判定・届いていない項目（項目名と今の値）・届いていない項目の数を出す
3. **すべての基準を満たしている銘柄の表**。1 行 1 銘柄で、丸い印・銘柄名（銘柄詳細へのリンク）・コード・市場・セクターを銘柄名順に出す。件数だけでは「どの銘柄が満たしているのか」が分からないため、名前を出す。1 件も無いときは表そのものを出さない
4. **注記**。該当する銘柄があるときだけ業種の注記（銀行・保険・証券、不動産）を出し、通期決算と 200日線の注意は常に出す

届いていない銘柄の表（2）に出すのは、基準に届いていない項目が 1 つ以上ある銘柄（判定が `broken` か `unmet`）だけ。**対象外（ETF）とデータなしの銘柄は件数だけ出し、どちらの表にも出さない。**

並び順は、見直し対象を先に、次に届いていない項目が多い順、同数なら銘柄名順。

絞り込みは、届いていない項目の種類で行う。ボタンは「すべて」と、届いていない銘柄が 1 件以上ある項目だけを、銘柄数の多い順に並べる（[countUnmetItems](../../src/lib/fundamental-check-summary.ts)）。市場で項目が違う（国内株は自己資本比率と有利子負債倍率、米国株は Altman Z）ため、ボタンは判定結果に入っている項目から作る。

購入時の指標をチェック開始日に一括で作った銘柄が 1 件以上あるときは、表より上に**買ったあとの変化がまだ比べられないこと**をお知らせとして出す。該当する銘柄数とチェック開始日を書く（ADR 0021 のプレモーテム）。

### 保有一覧

[holdings-client.tsx](../../src/components/holdings/holdings-client.tsx)。見出しと合計の枠の間に要約バーを出し、見直し対象・購入時から未達・満たしているの件数と、基準チェック一覧へのリンクを並べる。基準チェックが 1 件も読めなかったときはバーを出さない。

行の印は 2 種類で、判定ごとに出し分ける。基準チェック一覧の表でも同じ丸い印を使う。

| 判定 | 銘柄名の前（丸い印） | 銘柄名のうしろ |
| --- | --- | --- |
| 満たしている | 青い丸（`CircleCheck`） | 出さない |
| 見直し対象 | オレンジの丸（`CircleAlert`） | 「見直し対象」の文字バッジ |
| 購入時から未達・データなし・対象外 | 出さない | 出さない |

丸い印は `FundamentalStatusIcon`、文字バッジは `FundamentalBrokenBadge`（どちらも [fundamental-check-card.tsx](../../src/components/stocks/fundamental-check-card.tsx)）。

**丸い印は銘柄名の前に置き、印が無い銘柄も同じ幅を空ける。** 印の有無で銘柄名の開始位置がずれると、名前を縦に読めなくなるため。幅の予約は `FundamentalStatusIcon` が自分で行う（印が無い判定では同じ大きさの空きを返す）。

**見直し対象には文字バッジも出す。** 丸い印だけだと見落とすため、気づいてほしい判定は文字でも出す。

**購入時から未達には印を出さない。** 保有銘柄の多くが該当しうるため（2026-11-12 時点では 56 銘柄のうち 40 銘柄）、行ごとに印を出すと一覧の大半に印が並び、ほかの 2 つの印が埋もれる。件数は要約バー、内訳は基準チェック一覧で見る。

**満たしているの印を緑にしない。** 同じ行に評価損益のプラスを緑で出しているため、緑だと株価が上がっていることと見分けられなくなる。

**丸い印はツールチップで意味と次にすることを出す。** 色と形だけで意味を伝えないため。実装は Radix の Tooltip（[ui/tooltip.tsx](../../src/components/ui/tooltip.tsx)）で、`title` 属性は使わない。`title` はブラウザが出す素の吹き出しで、出るまで時間がかかり、見た目を揃えられず、キーボードでは出ないため。印はボタンにしてフォーカスを当てられるようにし、読み上げ用の文（「基準を満たしている」「見直し対象」）も持たせる。

### 銘柄詳細

[fundamental-check-card.tsx](../../src/components/stocks/fundamental-check-card.tsx) の「基準チェック」欄。見出しの横に判定のラベル、その下に一文、続いて項目ごとの表（項目と説明・基準・今・購入時・判定）を出す。表の下に、業種の注記、購入時の値の日付（チェック開始日の値ならその説明）、財務の値の期末と取得日時、価格の最終更新日時を出す。

## 画面に出さないこと

- **売買の指示。** 見直し対象は「売ってよい」ではなく、持ち続けるかを考え直すきっかけとして書く。どの画面にも「売買を勧めるものではありません」を添える
- **しきい値の変更。** 基準は固定で、設定画面からは変えられない（ADR 0021）
- **通知。** 見直し対象が出たことをメールなどで知らせる仕組みは無い（ADR 0021 の「決定していないこと」）
- **安値圏の判定。** 買うタイミングの条件なので、保有銘柄の判定では見ない（ADR 0021）
