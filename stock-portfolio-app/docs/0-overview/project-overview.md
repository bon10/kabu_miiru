# 株みーる - プロジェクト概要

## 📋 プロジェクトの目的

複数証券会社の口座を統合管理し、投資パフォーマンスを可視化・分析できるWebアプリケーション。証券会社のサイトでは蓄積されない過去の取引データを独自で集計・再整理してグラフ化し、投資家の資産状況を「見える化」することを目的とする。

## 🎯 プロジェクトの特徴

- **統合管理**: 複数証券会社の株式を一元管理
- **データ中心**: 提供されたTSVデータをベースとした銘柄管理
- **視覚化**: 投資状況をグラフで分かりやすく表示
- **履歴管理**: 取引履歴と価格履歴の詳細な記録
- **自動化**: 株価の自動取得とリアルタイム損益計算

## 🏗️ アーキテクチャ概要

- **フレームワーク**: Next.js 15 (App Router) + TypeScript
- **データベース**: MySQL + Prisma ORM
- **UI**: React 19 + Tailwind CSS + Radix UI
- **チャート**: Recharts
- **データフェッチング**: SWR

## 📋 主要機能

1. **銘柄一覧管理** - TSVベースの包括的な銘柄データ管理
2. **ポートフォリオサマリー** - 全体損益・配当・投資額の統計
3. **視覚化分析** - 構成比率とパフォーマンスのグラフ表示
4. **取引履歴管理** - 売買・配当取引の詳細記録と分析
5. **株価自動取得** - 定期的な価格更新とリアルタイム損益計算

## 🚀 現在の実装状況

### 実装済み機能

- **基本的なCRUD操作**: 銘柄の追加・編集・削除・一覧表示
- **TSVデータインポート**: 20列のTSVファイルからの銘柄データ取り込み
- **データベース設計**: Prismaスキーマによる完全なテーブル設計
- **株価取得機能**: Yahoo Finance APIを使用した価格取得（フォールバック付き）
- **ポートフォリオ分析**: 基本的な損益計算とサマリー表示

### 未実装機能

- **取引履歴管理**: 売買・配当取引の記録と分析
- **視覚化分析**: グラフによる構成比率とパフォーマンス表示
- **自動価格更新バッチ**: 定期的な株価更新処理
- **認証機能**: 現在は認証なしで動作（単一ユーザー想定）

## 🔧 開発環境

### セットアップ手順

```bash
# プロジェクトのクローン
git clone <repository-url>
cd stock-portfolio-app

# 依存関係のインストール
pnpm install

# データベースのセットアップ
pnpm db:push

# 開発サーバーの起動
pnpm dev
```

### データベース初期化

```bash
# スキーマの適用
pnpm db:push

# データベースの確認（Prisma Studio）
pnpm db:studio
```

## 📊 TSVデータ仕様

### ファイル形式

- **ファイル名**: `stock_template.tsv`
- **文字エンコーディング**: UTF-8
- **列数**: 20列
- **区切り文字**: タブ文字

### 列構成

| 列番号 | 列名           | データ型 | 説明             |
| ------ | -------------- | -------- | ---------------- |
| 1      | No             | 整数     | 連番             |
| 2      | 銘柄名         | 文字列   | 株式の正式名称   |
| 3      | 保有会社       | 文字列   | 証券会社名       |
| 4      | 市場           | 文字列   | 国内/米国        |
| 5      | コード         | 文字列   | 銘柄コード       |
| 6      | 保有株数       | 数値     | 現在の保有株数   |
| 7      | 平均取得単価   | 数値     | 平均購入価格     |
| 8      | 投資額         | 数値     | 総投資金額       |
| 9      | 現在価格       | 数値     | 最新株価         |
| 10     | 損益           | 数値     | 未実現損益       |
| 11     | 損益率         | 数値     | 損益の割合       |
| 12     | 1株配当金      | 数値     | 年間配当予想     |
| 13     | 配当利回り     | 数値     | 配当利回り       |
| 14     | 配当金額       | 数値     | 年間配当金額     |
| 15     | 購入日         | 日付     | 初回購入日       |
| 16     | 売却日         | 日付     | 完全売却日       |
| 17     | 実現損益       | 数値     | 売却による損益   |
| 18     | 目標価格       | 数値     | 利確・損切り目標 |
| 19     | 市場・セクター | 文字列   | 業種分類         |
| 20     | 目的           | 文字列   | 投資目的         |
