# 株みーる - プロジェクト概要

## 📋 プロジェクトの目的

複数証券会社の口座を統合管理し、投資パフォーマンスを可視化・分析できるWebアプリケーション。証券会社のサイトでは蓄積されない過去の取引データを独自で集計・再整理してグラフ化し、投資家の資産状況を「見える化」することを目的とする。

## 🎯 プロジェクトの特徴

- **統合管理**: 複数証券会社の株式を一元管理
- **データ中心**: 提供されたTSVデータをベースとした銘柄管理
- **視覚化**: 投資状況をグラフで分かりやすく表示
- **履歴管理**: 取引履歴と価格履歴の詳細な記録
- **自動化**: 株価の自動取得とリアルタイム損益計算

## 🏗️ アーキテクチャ概要

- **フレームワーク**: Next.js 15 (App Router) + TypeScript
- **データベース**: MySQL + Prisma ORM
- **UI**: React 19 + Tailwind CSS + Radix UI
- **チャート**: Recharts
- **データフェッチング**: SWR

## 📋 主要機能

1. **銘柄一覧管理** - TSVベースの包括的な銘柄データ管理
2. **ポートフォリオサマリー** - 全体損益・配当・投資額の統計
3. **視覚化分析** - 構成比率とパフォーマンスのグラフ表示
4. **取引履歴管理** - 売買・配当取引の詳細記録と分析
5. **株価自動取得** - 定期的な価格更新とリアルタイム損益計算
